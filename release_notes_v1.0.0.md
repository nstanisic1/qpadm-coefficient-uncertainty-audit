# v1.0.0

Versioned code and derived-output snapshot for:

**A reproducible audit of qpAdm coefficient uncertainty and complete-case allele-sharing diagnostics in medieval Balkan ancient DNA**

This version provides the reproducible Python workflow, derived matrices, statistical outputs, figures, environment files, run summary, checksum manifest, and data-use documentation supporting the associated manuscript.

## Archive and DOI

- GitHub release: https://github.com/nstanisic1/qpadm-coefficient-uncertainty-audit/releases/tag/v1.0.0
- Archived release DOI: https://doi.org/10.5281/zenodo.21276853
- Zenodo concept DOI: https://doi.org/10.5281/zenodo.21276852

## Repository Contents

- Eight-stage Python workflow for BAM/BAI validation, all-autosome matrix construction, allele-sharing diagnostics, coefficient-layer alpha analysis, alpha-threshold sensitivity analysis, figure generation, and complete-case distance-space audit.
- Strict complete-case pseudo-haploid 1240k matrices for the main panel and the Nustar E-V13 sensitivity panel.
- Machine-readable matrix summaries, allele-sharing summaries, coefficient-layer outputs, alpha-threshold sensitivity outputs, distance-space audit outputs, run metadata, and checksum manifest.
- Main figures and supplementary figures in PDF and PNG formats.
- Data-use documentation covering ENA BAM/BAI access, third-party source-file handling, the bundled public 1240k SNP coordinate resource, generated outputs, and license terms.
- Environment files for reproducing the Python analysis environment.

## Analysis Scope

This version supports a secondary-data computational audit. It does not redistribute large ENA BAM/BAI files, manuscript/submission files, or full third-party supplementary files. The analyses do not claim paternal-lineage origin, ethnic identity, homeland, direct continuity, or a uniquely identified unsampled source population.
